# [ENG] MonetLoader Libraries

Library pack required for mods to work on MonetLoader for SA-MP. Compatible with multiple architectures and versions. MonetLoader 3.6.0-os+.

## Support

- MonetLoader 3.6.0-os+
- SA-MP 0.3.7
- Architectures arm64-v8a, armeabi-v7a and x86_64
- Direct installation into the `lib` folder

## Installation

1. Download the file
2. Extract the contents
3. Copy the `lib` folder into `monetloader`:

```
Android/media/(your APK directory)/monetloader/
```

Requires MonetLoader 3.6.0-os+ and SA-MP 0.3.7
